# Portfolio Case Study

## Project Title

**Vertex Digital – Responsive Business Website**

### Project Overview

Vertex Digital is a responsive business website developed using HTML, CSS, and JavaScript. The website represents a digital agency and provides information about the company, its services, and contact details. It is designed to be user-friendly and fully responsive across different devices.

### Objectives

* Create a modern and responsive business website.
* Use semantic HTML5 for proper structure.
* Design an attractive interface using CSS3.
* Implement client-side form validation with JavaScript.

### Technologies Used

* HTML
* CSS
* JavaScript
* Font Awesome
* Google Fonts

### Features

* Responsive navigation bar
* Home, About, Services, and Contact sections
* Contact form with validation
* Responsive design for desktop and mobile
* Modern and professional user interface

### Challenges & Solutions

The main challenge was creating a responsive layout for different screen sizes. This was solved using Flexbox, CSS Grid, and media queries. JavaScript was used to validate the contact form before submission.

### Learning Outcomes

This project improved my skills in:

* Semantic HTML
* CSS Flexbox and Grid
* Responsive Web Design
* JavaScript Form Validation
* UI Design

### Conclusion

Vertex Digital demonstrates my ability to build a clean, responsive, and professional business website using front-end web technologies. The project meets all the assignment requirements while following modern web development practices.
